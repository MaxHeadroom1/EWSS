# EWSS example prompt

```text
@EWSS

Build a premium Arabic RTL website for [business/project name].

Requirements:
- Follow EWSS as the default design language.
- Adapt the colors and content to the brand.
- Light and dark mode.
- Responsive desktop, tablet, and mobile.
- Unified SVG outline icons.
- No emoji UI icons.
- No decorative 01/02/03 numbering.
- If a slider is used, use arrows + dots only.
- Avoid a generic AI-template appearance.
- Check that all images are relevant and not duplicated.
```
