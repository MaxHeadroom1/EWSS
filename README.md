# EWSS — Egypt Website Style

**Non-AI Front End for Egypt & Arab Websites**  
By **Mohamed Ali**

EWSS is a front-end design style guide and AI skill for building refined Arabic and Egyptian websites that avoid the generic “AI template” look.

## What EWSS focuses on

- Premium / refined / clean UI
- Native Arabic RTL layout
- Light + Dark mode by default
- Balanced, centered headers
- Clear, properly sized logos
- Unified SVG outline icons
- No emoji as UI icons
- No decorative numbering such as `01 / 03`
- Sliders use arrows + dots only when needed
- Strong image quality and correct image placement
- No accidental repeated images
- Overlay/gradient stays on the same side as the text
- Responsive desktop / tablet / mobile layouts
- Avoids oversized empty spaces and generic AI-looking card grids

## Suggested ChatGPT invocation

When installed as a ChatGPT plugin/skill, the intended invocation name is:

`@EWSS`

Example:

```text
@EWSS Design a premium Arabic RTL website for a real-estate company.
Use my brand colors and keep the UI clean, human-designed, responsive,
with light/dark mode and no generic AI-template styling.
```

> Important: publishing this GitHub repository alone does not automatically make `@EWSS` appear in ChatGPT. The skill still needs to be packaged/published through the supported ChatGPT plugin/skill flow.
