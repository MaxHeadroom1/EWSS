# مواصفات الذوق والتصميم للمواقع — Mohamed

> هذا الملف هو المرجع الافتراضي لأي موقع جديد ما لم يتم تحديد ستايل مختلف للمشروع.

## 1) الاتجاه العام
- التصميم **Premium / Refined / Clean** وليس قالب AI تقليدي.
- الواجهة مرتبة، واضحة، قليلة الزخرفة، وتعتمد على الصور والمساحات والتباين أكثر من المؤثرات.
- لا يتم نسخ هوية موقع سابق حرفيًا؛ تُطبّق نفس **لغة التصميم** مع ألوان وهوية المشروع الجديد.
- الواجهة العربية تكون **RTL حقيقية** في الترتيب والمحاذاة والحركة.
- دعم Desktop / Tablet / Mobile من البداية، وليس كتعديل لاحق.

## 2) الوضع الليلي والنهاري
- كل موقع جديد يدعم **Light Mode + Dark Mode** افتراضيًا.
- زر التبديل يكون بسيطًا وأنيقًا داخل الهيدر.
- يتم حفظ اختيار المستخدم محليًا.
- الوضع الليلي ليس مجرد قلب الأبيض إلى أسود:
  - خلفيات Charcoal / Near Black مريحة.
  - أسطح وكروت بدرجات أفتح قليلًا.
  - Borders هادئة.
  - Contrast واضح للنص.
  - الصور لا تُغسل بطبقة بيضاء أو Overlay مبالغ فيه.
- ألوان الـAccent الخاصة بالبراند تبقى واضحة في الوضعين.

## 3) الهيدر
- الهيدر **مضغوط رأسيًا** ولا يحتوي فراغات كبيرة غير مبررة.
- المحتوى يكون في Container متمركز فعليًا داخل الصفحة.
- في RTL يفضل الترتيب:
  - اللوجو جهة اليمين.
  - البحث في المنتصف عند الحاجة.
  - الحساب / المفضلة / السلة / إعدادات العرض جهة اليسار.
- توزيع الأعمدة يكون متوازنًا حتى لا يظهر فراغ كبير في جهة.
- اللوجو يكون **واضحًا وكبيرًا بدرجة مناسبة**، وليس صغيرًا داخل مساحة فارغة.
- شريط التنقل أسفل الهيدر مرتب ومتمركز.
- لا يظهر Scrollbar بصريًا في الهيدر أو شرائط التصنيفات.
- على الموبايل تتحول القائمة إلى Menu مدمج بدون كسر ترتيب الهيدر.

## 4) الأيقونات
- **ممنوع استخدام Emoji كأيقونات واجهة.**
- استخدم SVG Icons موحدة، والأفضل:
  - Outline.
  - Stroke متناسق.
  - نفس الحجم البصري.
  - نفس الـcorner/line language.
- لا تخلط بين Emoji وSVG وUnicode Symbols في نفس الواجهة.
- الأيقونات تكون وظيفية وليست مجرد زينة.

## 5) عناصر السلايدر
- لا تستخدم أرقامًا زخرفية مثل:
  - 01 / 03
  - 01 — 02 — 03
  - ترقيم الأقسام لمجرد الشكل.
- المستخدم **لا يفضّل الأرقام الديكورية** في المواقع.
- السلايدر عند الحاجة يستخدم:
  - سهم السابق.
  - سهم التالي.
  - Dots أو indicator بسيط.
- لا تضف مؤشر سلايدر لمجرد أن المرجع البصري يحتوي عليه؛ يجب أن يكون له وظيفة فعلية.

## 6) الصور
- استخدم صورًا بجودة جيدة ومناسبة للقسم.
- **ممنوع تكرار نفس الصورة لمنتجين/أقسام مختلفة** إلا إذا كان مقصودًا.
- تحقق أن كل صورة في مكانها الصحيح وأن محتواها يناسب اسم العنصر.
- توفير Fallback مناسب عند فشل مصدر الصورة.
- لا تترك Card بصورة فارغة أو مساحة سوداء/رمادية بدون قصد.
- `background-size: cover` وموضع الصورة يُضبط لكل حالة عند الحاجة.
- في المنتجات: الصورة أهم عنصر بصري ولا يجب تشويهها بـOverlay غير ضروري.

## 7) الكروت والعروض
- الكروت نظيفة وبسيطة، Borders رفيعة، وShadow محدود جدًا أو بدون Shadow.
- لا تستخدم Rounded Corners مبالغ فيها في كل شيء.
- لا تجعل كل Section مجموعة Cards متشابهة؛ التنويع مطلوب.
- في الكروت التي تحتوي صورة + Gradient/Overlay:
  - الـOverlay يكون **في نفس جهة النص**.
  - في RTL: إذا النص يمين، يكون تركيز الـOverlay يمين.
  - النص واللون لا يتحرك كل واحد في جهة مختلفة.
- الـCTA يبقى داخل حدود الكارت ولا يُقص.
- راعِ Contrast النص فوق الصور في Light/Dark Mode.

## 8) الألوان
- اللون الأساسي يتبع هوية المشروع.
- الخلفيات عادة:
  - Light: White / Warm Off-white / Soft Gray.
  - Dark: Charcoal / Near Black.
- Accent واحد أساسي، مع لون ثانوي عند الحاجة فقط.
- الأحمر للعروض/التحذير عند الحاجة، وليس كلون واجهة عام إلا إذا كان من البراند.
- تجنب كثرة Gradients والألوان النيون إلا لو المشروع يطلب ذلك.

## 9) الخطوط والنصوص
- العربية بخط Sans واضح واحترافي مثل Cairo أو الخط الخاص بالهوية.
- Hierarchy واضحة:
  - H1 قوي.
  - H2 أصغر بوضوح.
  - Body مريح.
- تجنب النصوص الصغيرة جدًا.
- لا تستخدم Text Shadow كحل للوضوح.
- النصوص مباشرة وقصيرة، خصوصًا في الـHero والكروت.

## 10) المساحات والمحاذاة
- المساحات البيضاء مهمة، لكن **لا تترك مساحات ميتة كبيرة**.
- كل عنصر يجب أن يبدو مقصودًا ومربوطًا بالـGrid.
- Containers متمركزة.
- لا تجعل المحتوى مزاحًا ناحية واحدة بدون سبب.
- اضبط Vertical Rhythm بين الأقسام باستمرار.
- الهيدر لا يأخذ مساحة رأسية أكبر من قيمته الوظيفية.

## 11) الـHero
- صورة أو Visual قوي + عنوان واضح + وصف قصير + CTA واحد أساسي.
- لا تزاحم الـHero بمعلومات كثيرة.
- يمكن استخدام Split Layout أو Full Width حسب المشروع.
- إذا فيه Slider:
  - الأسهم والـDots واضحة.
  - بدون ترقيم ديكوري.
- الـCTA بلون Accent ويظهر بوضوح.

## 12) المنتجات والمتاجر
- شبكة المنتجات متوازنة وتتكيف مع الشاشة.
- صورة المنتج كبيرة وواضحة.
- اسم المنتج، السعر، الخصم، المفضلة والسلة بترتيب بسيط.
- Badge مثل "خصم" أو "الأكثر مبيعًا" صغير وواضح.
- تجنب ازدحام Card بعناصر كثيرة.
- أزرار المفضلة والسلة تستخدم نفس نظام SVG Icons.
- تأكد من عدم تكرار الصور أو عدم تطابق الصورة مع اسم المنتج.

## 13) الحركة والتفاعل
- Hover بسيط وراقي:
  - تغير Background خفيف.
  - Translate بمقدار صغير جدًا.
  - Accent على Border أو Icon.
- لا تستخدم Animations كثيرة أو Bounce/Glow مبالغ فيه.
- الحركة يجب أن تخدم الفهم، لا أن تلفت النظر لنفسها.

## 14) ما يجب تجنبه دائمًا
- Emoji داخل الـUI.
- أرقام ديكورية بلا وظيفة.
- شكل واضح أنه مولد بقالب AI.
- مساحات فارغة ضخمة.
- تكرار الصور.
- صورة لا تطابق العنصر.
- Glow / Gradient / Glass effect في كل مكان.
- Shadows قوية.
- Rounded cards في كل Section.
- خلط أكثر من Style للأيقونات.
- عناصر Scroll ظاهرة بدون حاجة.
- Overlay أبيض يحرق الصور في Dark Mode.
- نقل النص لجهة والـOverlay للجهة الأخرى.
- Header غير متمركز أو مزاح ناحية واحدة.
- لوجو صغير داخل مساحة كبيرة.

## 15) Checklist قبل التسليم
- [ ] Light/Dark يعملان بشكل صحيح.
- [ ] الهيدر متزن ومتمركز.
- [ ] اللوجو واضح بالحجم المناسب.
- [ ] لا يوجد Emoji.
- [ ] الأيقونات SVG موحدة.
- [ ] لا توجد أرقام ديكورية.
- [ ] السلايدر له أسهم/Dots فقط عند الحاجة.
- [ ] لا يوجد Scrollbar بصري غير مطلوب.
- [ ] كل الصور تعمل.
- [ ] لا توجد صورة مكررة بالخطأ.
- [ ] الصور متوافقة مع أسماء العناصر.
- [ ] لا يوجد Card فارغ بسبب صورة فاشلة.
- [ ] الـOverlay في جهة النص.
- [ ] الوضع الليلي لا يحرق الصور أو النص.
- [ ] لا توجد مساحات ميتة كبيرة.
- [ ] Desktop / Tablet / Mobile تمت مراجعتها.
- [ ] النتيجة تبدو مخصصة للبراند وليست Template AI.

## قاعدة التنفيذ
عند بدء أي موقع جديد، اعتبر هذه المواصفات **Default Design Language**.
يمكن تغيير الألوان، نوع الصور، الـlayout التفصيلي، ونبرة البراند حسب المشروع،
لكن لا تُكسر القواعد أعلاه إلا إذا طلب المستخدم ذلك صراحة.
