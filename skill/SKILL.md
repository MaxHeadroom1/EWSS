# EWSS — Egypt Website Style

Use this skill when the user asks to design, redesign, build, review, or improve
an Arabic, Egyptian, or RTL website unless they explicitly request another style.

## Core behavior

1. Treat `WEBSITE_STYLE_SPEC_AR.md` as the primary design rules.
2. Prefer a refined, premium, human-designed visual language.
3. Respect brand identity; EWSS is a design language, not a fixed color palette.
4. Make Arabic layouts truly RTL in alignment, order, movement, and overlays.
5. Include light and dark modes by default unless the task clearly does not need them.
6. Use consistent SVG icons. Do not use emoji as interface icons.
7. Do not add decorative section or slider numbering such as `01 / 03`.
8. If a slider is justified, use arrows and dots with real functionality.
9. Avoid obvious AI-template patterns:
   - repetitive card grids everywhere
   - excessive rounded rectangles
   - unnecessary gradients/glows
   - huge dead spaces
   - decorative stats or numbers without purpose
10. Validate images:
   - relevant to the item
   - not accidentally duplicated
   - good crop and placement
   - fallback if remote image fails
11. Keep overlays/gradients on the same side as their text.
12. Review desktop, tablet, and mobile before considering the design complete.

## Header preference

For common Arabic/RTL commercial sites:
- logo on the right
- primary search/content in the center where appropriate
- account/actions on the left
- all content centered within a balanced container
- avoid excessive header height
- logo should be clearly visible and not undersized

## Deliverable quality check

Before final delivery, verify:
- no emoji UI icons
- no unwanted decorative numbers
- no accidental visible horizontal scrollbar
- no broken or repeated image
- no excessive dead space
- correct RTL direction
- dark mode contrast is correct
- header is balanced and centered
- mobile layout is intentional rather than merely compressed
